# gta6

A GTA-style open-world city game. 3D (three.js) and a 2D Phaser version.

## Setup

- `npm install`
- `npm run assets` — generate a random city map
- `npm run dev` — play at the dev server (3D game at `/`, 2D at `/2d.html`)

## Build

- `npm run build`, then `npm run preview`

## Controls

WASD walk · SHIFT sprint · arrows drive · E enter/exit vehicle · scroll zoom · T day/night
